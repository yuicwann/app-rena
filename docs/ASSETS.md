# Registry Aset — SinyalLab

Dokumen ini mencatat sumber, lisensi, dan atribusi seluruh aset non-kode (gambar, ikon, font, audio).
Semua aset wajib bersifat orisinal atau berlisensi CC0/Open Source bebas royalti.

| Aset | Tipe | Sumber / Pembuat | Lisensi | Catatan |
|------|------|------------------|---------|---------|
| Ikon aplikasi & Splash | Gambar | Orisinal | Proprietary (SinyalLab) | Dihasilkan dari template Expo / SinyalLab branding |
| Maskot SinyalLab | Vektor SVG | Orisinal | Proprietary (SinyalLab) | 3 ekspresi SVG (senang, berpikir, menyemangati) |
